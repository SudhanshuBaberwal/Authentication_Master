# 🔐 Advanced MERN Authentication System

A production-ready Authentication & Authorization system built using the **MERN Stack (MongoDB, Express, React, Node.js)** with secure JWT authentication, email verification using **Nodemailer**, password reset, refresh tokens, and modern security best practices.

---

## 🚀 Features

### 🔑 Authentication
- User Registration
- Secure Login & Logout
- JWT Access & Refresh Tokens
- Protected Routes (Frontend + Backend)
- Role-Based Authorization (Admin/User)
- Remember Me Option
- Logout from All Devices

### 📧 Email Integration (Nodemailer)
- Email Verification after Registration
- Password Reset via Email
- Account Activation Link
- Token Expiry Handling

### 🔒 Security Features
- Password Hashing with bcrypt
- HTTP-Only Secure Cookies
- Refresh Token Rotation
- Rate Limiting
- Helmet Security Headers
- CORS Protection
- Input Validation
- Environment Variables (.env)
- Secure Error Handling

### ⚡ Advanced Functionalities
- Profile Update
- Change Password
- Token Blacklisting
- Authentication Middleware
- Centralized Error Handling
- Clean MVC Architecture
